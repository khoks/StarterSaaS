# StarterSaaS

> Generic, white-label SaaS starter kit. Clone it, brand it, run one deploy script, and have a working multi-cloud SaaS up end-to-end.

**Status:** Phase A bootstrap (started 2026-04-25). No product code yet — repo skeleton, tracking system, and Claude Code automation only. Tech stack, cloud target, and MVP-1 scope lock during Phase B grooming.

**Phase plan:**

| Phase | Scope |
|---|---|
| **A — Bootstrap** *(in progress)* | Repo skeleton + Claude tooling + GitHub remote + MIT license |
| **B — Grooming** | Vision, requirements, architecture, tech stack, cloud target — interactive Q&A |
| **C — MVP-1 lockdown** | ~6 SaaS layers chosen, ADRs written, Stories decomposed |
| **D — MVP-1 build** | Implementation — thin vertical slice, one-script deploy |
